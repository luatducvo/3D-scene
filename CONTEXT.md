# S3D – Open-vocabulary 3D Scene QA

A local, single-user system: ingest prepared indoor 3D scans, then locate, highlight, and answer natural language questions about objects in the scene.

## Language

### Input data

**Scan**:
An RGB-D scan from ScanNet, identified by an ID of the form `scene0011_00`; the same room may have multiple scans (`_00`, `_01`).
_Avoid_: recording, capture

**Preprocessing**:
Normalizing the Scan and aligning its coordinate system completely outside the system; produces a Package for user upload. See [glossary](GLOSSARY.md) and ADR 0009.
_Avoid_: Import, Scene processing

**Package**:
An aligned `.s3dpkg` file generated by an independent script from a Scan, conforming to `s3dpkg/2`; the sole artifact accepted via upload.
_Avoid_: raw package, bundle, archive

**Scene**:
The internal representation of a scan within the system, with an identifier matching the scan ID; each scan has at most one scene.
_Avoid_: room (a room is a level within the scene graph), scan (when referring to ingested data)

**Import**:
Ingesting a package into the system: validating against the specification, copying into application storage, and creating or replacing the scene.
_Avoid_: upload (upload is the transport mechanism; Import is validation and Scene creation)

**Replace**:
Importing a different package for a scan that already has a scene, initiated intentionally by the user; the existing scene is deleted and reprocessed from scratch.
_Avoid_: overwrite, re-upload

**Keyframe**:
A retained color image + depth + pose within the package (1 in every 10 frames of the scan).
_Avoid_: frame

### Scene graph

**Instance**:
A proposed 3D mask (subset of mesh vertices) representing an individual object, without a label.
_Avoid_: proposal, segment

**Object**:
An instance assigned a label; an object-level node in the scene graph.
_Avoid_: item, entity

**Structure**:
The floor or a wall of the scene; an intermediate-level node in the scene graph.
_Avoid_: plane

**Room**:
The root node of the scene graph; each scene has exactly one room.

**Label**:
An open-vocabulary class name for an object, along with a confidence score and up to three alternative labels.
_Avoid_: class, category

**Predicate**:
A named geometric condition between nodes (e.g. `ON`, `NEAR`, `LEFT`), belonging to a fixed predicate library.
_Avoid_: relation (when referring to the condition)

**Relation**:
A precomputed predicate evaluated between two specific nodes and stored within the scene graph.
_Avoid_: edge, link

### Question answering

**Session**:
A multi-turn question sequence on a scene, preserving conversational references such as "it" or "this one".
_Avoid_: conversation, chat

**Lookup**:
A query consisting solely of a noun phrase, answered via label matching and embeddings without generating a program.
_Avoid_: search, simple query

**Program**:
A concise constraint program translated from a question, consisting of variables, constraints, selection operations, and a target.
_Avoid_: query plan

**Target**:
The variable that the question seeks to resolve.

**Anchor**:
An object serving as a reference point in a constraint, not the target.
_Avoid_: reference object

**Candidate**:
An object eligible to be bound to a variable.
_Avoid_: match

**Solution**:
An assignment of objects to all variables that satisfies every constraint in the program.
_Avoid_: result, answer

**Relaxation**:
Dropping or loosening the weakest constraint when a program yields no solutions.
_Avoid_: fallback

**Tiebreak**:
A step where a vision model selects among multiple solutions using a keyframe annotated with numbered candidates.
_Avoid_: arbitration, rerank

**Clarify**:
Prompting the user for clarification when multiple solutions remain, highlighting discriminating differences between them.

**Viewpoint**:
An origin and viewing orientation used to evaluate directional predicates: left, right, front, behind.
_Avoid_: camera viewpoint, camera angle

**Evidence**:
Keyframe images and solver metrics attached to an answer.
_Avoid_: proof
