# Working in backend/

The root [AGENTS.md](../AGENTS.md) applies here too. Run every `uv run tasks.py ...` command from
the repository root: the uv workspace and `tasks.py` live there, not in `backend/`.

## Read before you change

- **Which file holds what:** the code map in
  [overview.md](../docs/architecture/overview.md#code-map).
- **Stages, Algorithms, Workspace, Job runner:** [pipeline.md](../docs/architecture/pipeline.md).
- **Targets, `scene-compute`, `backend/deploy/`, `compute.yaml`:**
  [compute.md](../docs/architecture/compute.md).
- **Routes, SSE events, migrations, the QA agent:** [api.md](../docs/architecture/api.md).
- **A new Algorithm, Relation, QA tool or provider:** the change-point table in
  [extending.md](../docs/architecture/extending.md); each recipe names every file it touches.

## Rules

- Packages depend downward only: `scene-core` ← `scene-stages` ← the services. `scene-core` stays
  free of `torch`, `fastapi` and database drivers; heavy model dependencies go in an optional extra
  of `scene-stages`.
- Every real Algorithm has a fake in
  [scene_stages/fake.py](packages/scene-stages/src/scene_stages/fake.py), and tests in `tests/` run
  the fake. Name Algorithms `<stage>.<method>` and register them as entry points in
  [scene-stages/pyproject.toml](packages/scene-stages/pyproject.toml).
- Choosing a method or provider is a configuration change in `config/pipeline*.yaml`,
  `config/compute.yaml` and `.env`. Add new variables to `.env.example`; `backend/.env` holds the
  user's secrets.
- A schema change is a new numbered, idempotent file in `migrations/`; existing migrations stay as
  they are. `SceneStore.migrate` applies each file once, recorded in `schema_migrations`, when the
  api or worker starts, so a running stack picks up a new one on restart without deleting Scenes.
- Failures surface as an error code from
  [scene_core/errors.py](packages/scene-core/src/scene_core/errors.py). This is a learning
  project: a failing component fails the Stage, with no fallback path.
- `openapi/openapi.json` is generated by `uv run tasks.py openapi`.
